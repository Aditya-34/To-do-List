# ✅ To-Do List App

A simple and responsive **Task Manager** web app built with **HTML, Bootstrap, and JavaScript**.  
Add, complete, and delete your daily tasks — all in a clean, mobile-friendly UI.

## 🛠️ Built With

- **HTML5** — Structure
- **CSS3** — Styling
- **Bootstrap 5** — Responsive design
- **JavaScript (Vanilla)** — Logic & DOM manipulation

---

## ✨ Features

- ➕ Add new tasks instantly
- ✅ Mark tasks as completed
- 🗑️ Delete tasks you no longer need
- 📱 Fully responsive — works on mobile & desktop
- ⚡ No page reload — all dynamic with JavaScript

---

## 📂 Project Structure

```
todo-list/
│
├── index.html       # Main HTML file
├── style.css        # Custom styles
└── script.js        # JavaScript logic
```

## ▶️ How to Run

1. Clone the repository
   ```bash
   git clone https://github.com/Gen_x_coder/todo-list.git
   ```
2. Open `index.html` in your browser
3. That's it — no setup needed!
